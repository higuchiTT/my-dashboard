# メール取り込み（楽天カード・三菱UFJデビット・JCB）（Apps Script）

楽天カードの「カード利用のお知らせ」（確定版）、三菱UFJ-VISAデビットの「ご利用のお知らせ」、JCBカードの「ショッピングご利用のお知らせ」（利用時の通知と売上到着分。取消は除く）メールを、ダッシュボードの Ledger に「未確認」として取り込むための小さな Web アプリです。
楽天の速報版は対象外です。メールの解析はダッシュボード側で行います。ファイル名は `rakuten-mail.gs` のままですが、両方を扱います。

## 三菱UFJデビット・JCBを追加するとき（すでに楽天だけ設定済みの場合）

1. Apps Script のエディタで、コードを新しい `rakuten-mail.gs` の内容に丸ごと置き換えて保存する。
2. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」→「デプロイ」。URL は変わりません。
3. Ledger →「設定」で「三菱UFJデビットの口座」「JCBカードの口座」を選ぶ。
（古いコードのままでも、楽天は今までどおり動きます。）

## セットアップ

1. https://script.google.com を開き、新しいプロジェクトを作る（名前は何でもよい）。
2. `Code.gs` の中身を消して、このフォルダの `rakuten-mail.gs` の内容を貼り付ける。
3. 左の「プロジェクトの設定」（歯車）を開き、「スクリプト プロパティ」に次を追加する。
   - プロパティ: `TOKEN`
   - 値: 長いランダムな文字列（30 文字以上。パスワード管理ツールで作るのがおすすめ）
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 初回は Gmail へのアクセス許可を求められるので承認する（「このアプリは確認されていません」と出たら「詳細」から進む）。
6. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/.../exec`）をコピーする。
7. ダッシュボードの Ledger →「設定」→「メールから取り込み（楽天カード・三菱UFJデビット・JCB）」に、URL と手順 3 のトークンを入れる。楽天カード・三菱UFJデビット・JCBカードの口座を選び、「接続を確かめる」を押す。

## 注意

- コードを直したあとは、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」で再デプロイが必要です（保存しただけでは反映されません）。
- URL とトークンを知っている人は、この楽天カード・三菱UFJデビット・JCBのお知らせメールだけ読めます。他人に見せないでください（このリポジトリは公開なので、書き込まないこと）。
- 流出したら、スクリプトプロパティの `TOKEN` を変えるか、デプロイを削除してください。ダッシュボードの設定も同じ値に更新します。
